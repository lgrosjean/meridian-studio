# Roadmap

Meridian (2.1) can do more than the extension uses today. This page lists what is still missing, grouped by area,
the most useful first in each. For each feature, it names Meridian's API, then what it would become in the
extension: a YAML key, a check in Problems, a section of the results.

| Area        | Feature                                    | Meridian's API                                                                                     | In the extension                                                                                              | Status    |
|-------------|--------------------------------------------|----------------------------------------------------------------------------------------------------|---------------------------------------------------------------------------------------------------------------|-----------|
| Fit quality | Meridian's review of a fit                 | `Meridian.review()` → `ReviewSummary`                                                              | health score and checks in the results panel, Problems, the tree, Meridian Runs and MLflow; the health card  | Unreleased |
|             | The review's thresholds, as code           | `ConvergenceConfig`, `BaselineConfig`, `ImplausibleROIConfig`… passed to `review()`                | a `review:` block in a model, like a dataset's `checks:`: thresholds, checks turned off                       | Planned   |
|             | Review again without refitting             | `ModelReviewer(model_context, inference_data)` on the saved model                                  | **Review** above a model: the latest fit reviewed again, after a threshold changed                             | Planned   |
|             | Holdout, accuracy out of sample            | `ModelSpec(holdout=HoldoutSpec(...))`: `DateRange`, `GeoHoldoutSpec`, `RandomHoldoutSpec`          | `model_spec.holdout: { last: 8 }` (or dates, geos, a random share); R², MAPE on the weeks held out            | Planned   |
|             | Meridian's other data checks               | `EDASpec`; `EDAEngine.check_std`, `check_cost_per_media_unit`, `check_data_param_ratio`…           | an `eda:` block in a model for their thresholds; new codes in Problems                                        | Planned   |
|             | Meridian's EDA report                      | `MeridianEDA(mmm).generate_and_save_report(...)`                                                   | the data's report beside the fit's, in MLflow and in the editor                                               | Planned   |
|             | r-hat by parameter                         | `Analyzer.rhat_summary()`                                                                          | the parameters that did not converge, not only the largest r-hat                                              | Planned   |
| Priors      | Calibration by lift tests                  | `CalibrationBuilder.with_incrementality_experiment_result(...)` → `CalibratedPriors`               | an `experiments:` CSV of lift tests, turned into each channel's ROI prior                                     | Planned   |
|             | When an ROI prior applies                  | `ModelSpec(roi_calibration=CalibrationSpec(...))`                                                  | `roi_calibration` by dates or channels; today handed to Meridian untranslated                                 | Planned   |
|             | Knots by date, chosen with constraints     | `knots.AKS(data).automatic_knot_selection(...)`, `Meridian.knot_info`                              | `knots:` as dates, knots required or excluded; the knots chosen, in the results                               | Planned   |
|             | A LogNormal from a range                   | `prior_distribution.lognormal_dist_from_range(low, high)`                                          | `{ dist: LogNormal, range: [0.5, 3] }`                                                                        | Planned   |
|             | Sampler options                            | `sample_posterior(max_tree_depth=..., dual_averaging_kwargs=...)`; `MCMCOOMError`                  | `sampling.target_accept_prob`, `max_tree_depth`; out of memory, a message saying what to lower                | Planned   |
| Data        | A dataset from several CSVs                | `DataFrameInputDataBuilder.with_kpi`, `with_media`, `with_controls`, `with_population`…            | the KPI, the media, the controls and the population per geo, each from its own CSV                            | Planned   |
|             | Organic channels named                     | `with_organic_media(..., organic_media_channels=...)`                                              | `organic_media_to_channel`, as for paid media (today a channel is named after its column)                     | Planned   |
|             | The largest geos only                      | `InputData.get_n_top_largest_geos(n)`                                                              | `geos: { top: 50 }` in a dataset                                                                              | Planned   |
|             | More of what Meridian refuses, as checks   | `InputData`'s validation; `common.currency.is_valid_currency_code`                                 | revenue per KPI all zero, empty cells in controls or spend, an unknown currency; quarterly and yearly dates (T002 takes weekly and monthly ones only) | Planned |
| Results     | More metrics by channel                    | `Analyzer.summary_metrics()`: `mroi`, `cpik`, `effectiveness`, `incremental_outcome`; the prior's  | in the results panel and MLflow; prior against posterior                                                      | Planned   |
|             | Response, adstock and Hill curves          | `Analyzer.response_curves()`, `adstock_decay()`, `hill_curves()`                                   | charts in the results panel                                                                                   | Planned   |
|             | The fit over time, the baseline            | `Analyzer.expected_vs_actual_data()`, `baseline_summary_metrics()`                                 | expected against actual KPI, week by week; the baseline's share                                                | Planned   |
|             | Optimal frequency                          | `Analyzer.optimal_freq()`                                                                          | each reach and frequency channel's optimal frequency                                                          | Planned   |
| Scenarios   | Reach and frequency channels               | `BudgetOptimizer` results along `rf_channel`                                                       | scenarios list only impression channels today, and a model with reach and frequency channels alone cannot be optimized | Planned |
|             | Scenarios on future weeks                  | `optimize(new_data=...)`, `create_optimization_tensors(...)`                                       | new costs and flighting in a scenario: next quarter's plan                                                    | Planned   |
|             | More of the optimizer                      | `optimize(pct_of_spend=..., use_posterior=..., max_frequency=..., selected_geos=...)`              | a starting mix, an optimization on the priors alone, a scenario on some geos                                  | Planned   |
|             | Fast scenarios                             | `create_optimization_grid(...)`, `WeeklyOptimizationGrid`                                          | the grid built once per fit, each scenario then in seconds                                                    | Planned   |
|             | mROI, CPIK and profit, before and after    | `OptimizationResults.optimized_data`, `nonoptimized_data`                                          | in a scenario's results and MLflow                                                                            | Planned   |
| Sharing     | The model and its analyses in one file     | `schema.mmm_proto_generator.create_mmm_proto(mmm, [ModelFitSpec(), MarketingAnalysisSpec(...), BudgetOptimizationSpec(...)])` | an `mmm.binpb` in MLflow; its tables as CSV (`scenarioplanner`'s converters)              | Planned   |
|             | The saved model, complete                  | `MeridianSerde().serialize(mmm, model_id=..., include_convergence_info=True)`                      | the MLflow run as the model's id; r-hat and the trace in `model.binpb`                                        | Planned   |
|             | Google's Scenario Planner                  | `scenarioplanner`: Google Sheets, Looker Studio                                                    | a fit opened in Scenario Planner; needs Google credentials, and sends the data to Google Drive               | Idea      |
|             | GPU, precision                             | the `and-cuda` extra; `MERIDIAN_ENABLE_JAX_X64`                                                    | settings for the runner's environment                                                                         | Idea      |
